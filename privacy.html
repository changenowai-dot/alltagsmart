Datenschutzerklärung / Privacy Policy

Stand: 27. Oktober 2026

Der „Alltagsmart Uploader“ ist ein privates Werkzeug, das ausschließlich vom Inhaber des YouTube-Kanals Alltagsmart genutzt wird, um die eigenen Videos dieses Kanals über die YouTube Data API hochzuladen und zu terminieren.

Genutzte Daten

Mit Zustimmung des Inhabers nutzt das Werkzeug die Berechtigungen youtube.upload und youtube.readonly, um Videos hochzuladen und zu prüfen, dass es mit dem richtigen Kanal verbunden ist. Daten anderer Nutzer werden nicht abgerufen.

Speicherung und Weitergabe

Das OAuth-Token wird nur auf dem eigenen Computer des Inhabers gespeichert. Es werden keine Daten verkauft, an Dritte weitergegeben oder für Werbung genutzt. Die Nutzung von Informationen aus Google-APIs entspricht der Google API Services User Data Policy einschließlich der Limited-Use-Anforderungen.

Widerruf

Der Zugriff kann jederzeit unter myaccount.google.com/permissions widerrufen werden.

English: The "Alltagsmart Uploader" is a private tool used only by the owner of the Alltagsmart YouTube channel to upload and schedule that channel's own videos via the YouTube Data API (scopes youtube.upload and youtube.readonly). The OAuth token is stored only on the owner's computer; no data is sold or shared. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at myaccount.google.com/permissions.
